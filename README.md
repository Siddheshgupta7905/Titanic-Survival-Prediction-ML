# Titanic-Survival-Prediction-ML
Machine Learning project based on the Titanic dataset from Kaggle. The dataset contains passenger details such as Age, Gender, Passenger Class, Fare, Embarked Location, and Family Information. Using these features, the model predicts passenger survival.

## Tech Stack

Python, Pandas, NumPy, Scikit-learn, Jupyter Notebook

## Features

* Data preprocessing
* Handling missing values
* Feature encoding
* Model training
* Survival prediction
